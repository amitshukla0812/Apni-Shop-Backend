Apni product/category/brand image files yahan is folder ke andar, unke
original relative path ke saath rakh dein. Jaise agar product ka "pic"
field "product/p3.jpg" hai, toh file yahan honi chahiye:

    uploads/product/p3.jpg

Backend chalu hone par ye file is URL par accessible ho jayegi:

    http://localhost:8000/uploads/product/p3.jpg
